# nyj_lxh_zlf_game

## 项目简介

同济大学软件工程专业《程序设计范式》课程期末大项目。

本项目基于 C++ 语言开发，采用 Cocos2d-x 游戏开发框架，实现了一款具有完整游戏逻辑、交互机制以及图形界面的 2D 游戏程序。

项目主要目标是通过面向对象程序设计思想，完成游戏系统的模块化设计，包括角色管理、场景控制、资源加载、事件处理以及游戏逻辑实现等功能。

## 功能介绍

### 1. 游戏场景系统

项目通过场景管理机制组织不同游戏界面，实现：

* 游戏主菜单
* 游戏运行场景
* 游戏结束界面
* 场景之间的切换

---

### 2. 游戏对象管理

通过面向对象方式设计游戏中的核心对象，包括：

* 玩家角色
* 游戏实体
* 道具或交互对象
* 游戏状态对象

每个对象拥有独立的数据结构和行为逻辑，提高代码复用性。

---

### 3. 用户交互系统

实现玩家与游戏环境之间的交互，包括：

* 键盘输入处理
* 游戏事件响应
* UI 控件交互
* 游戏状态更新

---

### 4. 资源管理

项目统一管理游戏资源，包括：

* 图片素材加载
* 动画资源管理
* 音频资源调用
* 游戏配置读取

减少资源重复加载，提高运行效率。

---

## 核心设计思想

### 面向对象设计

项目采用面向对象思想，将游戏中的不同模块抽象为独立类：

* 封装对象属性与行为
* 降低模块之间耦合
* 提升代码扩展能力

---

### 模块化架构

游戏逻辑按照功能划分：

```
用户输入
    ↓
事件处理
    ↓
游戏状态更新
    ↓
对象逻辑执行
    ↓
图形渲染
```

## 编译运行

### 环境要求

推荐环境：

* Windows 10/11
* Visual Studio
* CMake
* Cocos2d-x 环境

---

### 方法一：Visual Studio 运行

1. 使用 Visual Studio 打开：

```
proj.win32
```

目录下的工程文件。

2. 配置编译环境：

```
Debug / Release
x86 或 x64
```

3. 点击：

```
生成 → 运行
```

即可启动游戏。

---

### 方法二：CMake 编译

进入项目根目录：

```bash
mkdir build
cd build

cmake ..
```

随后根据生成的工程文件进行编译。
