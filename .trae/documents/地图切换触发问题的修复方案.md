# 地图切换触发问题的修复方案

## 问题根因
玩家位置（世界坐标）与传送点区域（地图坐标）使用了不同的坐标系统，导致碰撞检测失败。

## 修复步骤

### 1. 修改 isPlayerInTeleportZone 函数
将玩家世界坐标转换为地图坐标：
```cpp
bool GameScene::isPlayerInTeleportZone(const Rect& zoneRect)
{
    if (!player || !tileMap) return false;
    
    Vec2 playerPos = player->getPlayerPosition();
    Vec2 mapWorldPos = tileMap->getPosition();
    
    Vec2 playerOnMap(playerPos.x - mapWorldPos.x, playerPos.y - mapWorldPos.y);
    
    float playerWidth = 32.0f;
    float playerHeight = 48.0f;
    
    Rect playerRect(playerOnMap.x - playerWidth / 2, 
                   playerOnMap.y - playerHeight / 2, 
                   playerWidth, playerHeight);
    
    return playerRect.intersectsRect(zoneRect);
}
```

### 2. 添加调试日志
在checkTeleportPoints中添加日志，输出关键坐标值用于验证：
- 玩家世界坐标
- 地图世界坐标  
- 计算后的玩家地图坐标
- 传送点区域坐标

### 3. 验证方法
运行游戏，移动到传送点区域，检查日志输出，确认坐标转换正确。
