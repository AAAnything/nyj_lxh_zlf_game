# 基于TMX对象层的地图切换与人物传送系统实现

## 一、修改 MenuManager
1. 在 `MenuManager.h` 中添加新方法声明：
   - `void switchToGameSceneWithMap(const std::string& tmxFile, const cocos2d::Vec2& playerPos)`
2. 在 `MenuManager.cpp` 中实现该方法：
   - 创建 GameScene 时传入地图文件和玩家位置
   - 调用 switchScene 切换场景

## 二、修改 GameScene
1. 在 `GameScene.h` 中添加：
   - 静态方法 `static cocos2d::Scene* createSceneWithMap(const std::string& tmxFile, const cocos2d::Vec2& playerPos)`
   - 成员变量 `_currentMapFile` 存储当前地图文件名
   - 私有方法 `void checkTeleportPoints()` 用于检测传送点碰撞

2. 在 `GameScene.cpp` 中：
   - 实现 `createSceneWithMap` 静态方法
   - 修改 `init()` 支持通过参数初始化地图和玩家位置
   - 在 `update()` 中调用 `checkTeleportPoints()`
   - 实现传送点检测逻辑：
     - 获取对象层 "teleport"
     - 遍历所有对象，检测玩家是否进入碰撞区域
     - 读取 targetMap、targetX、targetY 属性
     - 调用 MenuManager::switchToGameSceneWithMap 切换场景

## 三、修改 Player
1. 在 `Player.h` 中添加：
   - 公有方法 `void setPosition(const cocos2d::Vec2& pos)` 的重写或使用基类方法

## 四、地图文件准备
1. 确保 forestMap.tmx 和 beachMap.tmx 中包含正确的传送点对象层配置

## 实现流程
```
玩家进入传送区域 → 检测碰撞 → 读取TMX属性 → MenuManager切换场景 → 新地图加载 → 玩家出现在目标位置
```
